# CARLTON FL — Overleaf package

Upload this entire folder to Overleaf (New Project → Upload Project), or zip it first.

## Compile

1. Set **main.tex** as the main document (Menu → Main document).
2. Compiler: **pdfLaTeX** (default).
3. Recompile twice so cross-references settle.

`IEEEtran.cls` is included. Required figures live under `figs/`.

## Contents

| File | Role |

| `main.tex` | Paper source (`paper_frl_carlton.tex`) |
